# Getting started

Get debugger running in your project in under two minutes. This guide
covers installation and basic usage. For framework-specific setup, see
the guides linked below.

## Install

Add `@ephem-sh/debugger` as a dev dependency:

```bash
# npm
npm install -D @ephem-sh/debugger

# pnpm
pnpm add -D @ephem-sh/debugger

# bun
bun add -D @ephem-sh/debugger

# yarn
yarn add -D @ephem-sh/debugger
```

## Use the CLI

Once your dev server is running with debugger instrumented, query it
with `dbg`:

```bash
# Check session status
npx dbg status

# View browser console logs
npx dbg browser console

# View server console logs
npx dbg server console

# View everything
npx dbg all

# JSON output for agents
npx dbg browser console --json
```

With bun:

```bash
bunx dbg status
bunx dbg browser console
```

## CLI overview

The CLI uses a two-level command structure split by where the data
comes from:

```
dbg <scope> <command> [flags]
dbg <command> [flags]
```

**Scopes:**
- `browser` — browser-side data (console, network, errors, cookies,
  storage, workers, cache, permissions, quota)
- `server` — server-side data (console, errors)

**Top-level commands:**
- `status` — session info
- `all` — everything merged (default)

Run `npx dbg --help` for the full command and flag reference.
