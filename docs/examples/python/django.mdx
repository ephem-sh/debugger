# Python + Django

This guide covers adding debugger to a
[Django](https://djangoproject.com) project. The setup takes one
line in your settings file.

## Prerequisites

- Python 3.10 or later
- Django 4.2 or later

## Install

```bash
pip install ephem-debugger[django]
```

Or with uv:

```bash
uv add ephem-debugger[django]
```

## Set up

Add the middleware to your Django settings:

```python
# settings.py
MIDDLEWARE = [
    "ephem_debugger.middleware.django.DebuggerMiddleware",
    # ... other middleware
]

# Optional: set the port (defaults to 8000)
DEBUGGER_PORT = 8000
```

One line in `MIDDLEWARE` handles everything — log store, IPC bridge,
console capture, and HTTP request logging.

## What gets captured

- **HTTP requests** — method, path, status code, and latency for
  every request
- **Root logger output** — the debugger handler is added to the root
  Python logger, capturing all `logging.info()`, `logging.error()`,
  etc. calls throughout your Django app

## Verify

Start your server:

```bash
python manage.py runserver
```

Open another terminal and query:

```bash
dbg status
dbg server console
```

## Production safety

Django only runs the middleware when it's in the `MIDDLEWARE` list.
Guard it for production:

```python
# settings.py
MIDDLEWARE = [...]

import os
if os.getenv("DEBUG") == "1":
    MIDDLEWARE.insert(0, "ephem_debugger.middleware.django.DebuggerMiddleware")
```

## Browser support

If your application serves HTML pages, the debugger automatically
captures browser-side data. The middleware:

- Serves the browser client script at `/_/d.js`
- Handles browser log ingest at `POST /_/d`
- Auto-injects script tags into HTML responses before `</body>`

No additional setup is needed. Query browser data with:

```bash
dbg browser console       # browser console logs
dbg browser errors        # runtime errors
dbg browser network       # fetch/XHR requests
dbg browser cookies       # document cookies
dbg browser storage       # localStorage + sessionStorage
```
